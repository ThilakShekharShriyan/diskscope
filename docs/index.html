09 · Methodology

How to read these numbers

Benchmark design follows Hoefler & Belli's rules for reporting performance results, criterion.rs, hyperfine, fio and ClickBench practice.

Statistics

  • Medians, never mean ± σ: latency is skewed and bounded at zero.
  • Median intervals from order statistics: exact coverage, no distributional assumptions.
  • Ratios use a seeded two-sample bootstrap (4,000 resamples), so the page is reproducible.
  • No outliers are removed.

Fairness

  • Identical Python guest on both sides; comparisons use guest-measured work only.
  • Local fsync uses F_FULLFSYNC so both sides pay for durability.
  • Archil runs from v0.1 on shuffle (task, trial) order and record the seed; the first sequential Archil run and the local baseline ran in fixed task order.
  • Image warm-up is recorded but kept out of every statistic.

Limits

  • One region, one client location, one disk; small n per cell.
  • Fan-out is closed-loop: no throughput-at-load claims (coordinated omission).
  • seq-read is warm-cache; no cold-read claims.
  • Archil's queue time includes VM claim and mount; it is not raw Firecracker boot.
